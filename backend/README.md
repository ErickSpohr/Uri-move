## Sobre o Laravel

Laravel é um framework para aplicações web com uma sintaxe expressiva e elegante. Acreditamos que desenvolver deve ser uma experiência agradável e criativa. O Laravel simplifica tarefas comuns em muitos projetos web, como:

- [Mecanismo de rotas simples e rápido](https://laravel.com/docs/routing).
- [Contêiner poderoso para injeção de dependências](https://laravel.com/docs/container).
- Vários backends para armazenamento de [sessões](https://laravel.com/docs/session) e [cache](https://laravel.com/docs/cache).
- [ORM expressivo e intuitivo para bancos de dados](https://laravel.com/docs/eloquent).
- [Migrações de esquema independentes do banco de dados](https://laravel.com/docs/migrations).
- [Processamento robusto de tarefas em segundo plano](https://laravel.com/docs/queues).
- [Transmissão de eventos em tempo real](https://laravel.com/docs/broadcasting).

Laravel é acessível, poderoso e oferece as ferramentas necessárias para aplicações robustas de grande porte.

## Aprenda Laravel

Laravel oferece uma [documentação](https://laravel.com/docs) abrangente e uma biblioteca de tutoriais em vídeo, facilitando o início com o framework.

Além disso, o [Laracasts](https://laracasts.com) reúne milhares de tutoriais em vídeo sobre diversos temas, incluindo Laravel, PHP moderno, testes unitários e JavaScript. Aprimore suas habilidades explorando essa biblioteca.

Você também pode assistir a aulas curtas com projetos reais no [Laravel Learn](https://laravel.com/learn), que ensina a criar uma aplicação Laravel do zero enquanto apresenta os fundamentos do PHP.

## Desenvolvimento com agentes de IA

A estrutura previsível e as convenções do Laravel o tornam adequado para agentes de programação com IA, como Claude Code, Cursor e GitHub Copilot. Instale o [Laravel Boost](https://laravel.com/docs/ai) para aprimorar seu fluxo de trabalho com IA:

```bash
composer require laravel/boost --dev

php artisan boost:install
```

O Boost oferece ao seu agente mais de 15 ferramentas e habilidades para ajudar na criação de aplicações Laravel seguindo as boas práticas.
